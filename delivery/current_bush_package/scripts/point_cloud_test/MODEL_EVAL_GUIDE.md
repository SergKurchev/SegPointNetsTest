# Метрики для сравнения моделей point-cloud segmentation

Для задачи 2 стоит считать минимум такой набор:

- `mIoU` - главная метрика сегментации, хорошо показывает качество по классам при дисбалансе.
- `per-class IoU` - отдельно для `background`, `ripe`, `half-ripe`, `unripe`.
- `macro F1` - удобна как дополнительная метрика, особенно если классы редкие.
- `overall accuracy` - полезна, но не должна быть единственной из-за сильного фона.
- `mean class accuracy` - помогает увидеть, не игнорирует ли модель редкие классы.
- `inference latency / sample` - важна, если модель потом пойдёт в near-real-time пайплайн.

## Рекомендуемый вывод по 4 моделям

Для каждой модели в отчёте держать:

- название модели
- train/inference command
- overall accuracy
- macro F1
- mIoU
- per-class IoU
- среднее время инференса на sample
- короткий вывод: сильные стороны, слабые стороны, итоговая рекомендация

## Правило выбора лучшей модели

Практичное правило для этого проекта:

1. Сначала сортировать по `mIoU`.
2. Если разница маленькая, смотреть `ripe/half-ripe/unripe IoU`, а не только фон.
3. Если качество близкое, выбирать модель с меньшим inference time и более простым запуском.
